## Tech Stack - Python

### Framework & Runtime
- **Application Framework:** FastAPI (for APIs) or Django (for full-stack)
- **Language/Runtime:** Python 3.11+
- **Package Manager:** uv (fast Python package installer and resolver)
- **Virtual Environment:** uv venv (built into uv)

### Backend
- **Web Framework:** FastAPI (async, high performance) or Flask (lightweight) or Django (batteries-included)
- **ASGI Server:** Uvicorn (for FastAPI/async) or Gunicorn (for sync/Django)
- **Task Queue:** Celery with Redis broker, or Dramatiq (lightweight alternative)
- **Background Jobs:** Celery Beat for scheduled tasks, or APScheduler

### Database & Storage
- **Database:** PostgreSQL (primary), SQLite (development/testing)
- **ORM:** SQLAlchemy 2.0 (with async support) or Django ORM
- **Migrations:** Alembic (for SQLAlchemy) or Django migrations
- **Caching:** Redis with redis-py
- **Object Storage:** Azure Blob Storage, or MinIO (S3-compatible, self-hosted)

### API Design
- **API Style:** RESTful with OpenAPI/Swagger documentation (auto-generated by FastAPI)
- **Serialization:** Pydantic models (FastAPI) or Django REST Framework serializers
- **Authentication:** JWT tokens via python-jose or PyJWT

### Testing & Quality
- **Test Framework:** pytest with pytest-asyncio for async tests
- **Coverage:** pytest-cov for code coverage reporting
- **Mocking:** pytest-mock, unittest.mock, or responses for HTTP mocking
- **Linting:** Ruff (fast, all-in-one linter and formatter - open source)
- **Type Checking:** mypy with strict mode enabled
- **Formatting:** Ruff format (replaces Black + isort in one tool)

### Deployment & Infrastructure
- **Containerization:** Docker with multi-stage builds
- **Local Hosting:** Docker Compose, or direct execution with systemd/Supervisor
- **Azure Hosting:** Azure Container Apps, Azure App Service, or Azure Kubernetes Service (AKS)
- **CI/CD:** GitHub Actions (free for public repos) or Azure DevOps Pipelines
- **Process Manager:** Supervisor, systemd, or Azure's built-in process management

### Third-Party Services
- **Authentication:** Keycloak (open source), Azure AD/Entra ID, or custom JWT implementation
- **Email:** Azure Communication Services, or Mailpit (local development)
- **Monitoring:** Sentry (free tier), or Prometheus + Grafana (self-hosted, open source)
- **Logging:** structlog for structured logging, shipped to Azure Monitor or Loki (open source)

### Development Tools
- **Package Management:** `uv pip install`, `uv sync` for dependency management
- **Dependency File:** `pyproject.toml` with uv-compatible format
- **Lock File:** `uv.lock` for reproducible installations
- **Pre-commit:** pre-commit hooks with Ruff checks
